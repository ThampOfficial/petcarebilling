# Pet Care Billing

A single-page web app for cat-sitting invoices, built from `Billing.xlsx`.

- **Rate catalog** – drop-in, boarding and pickup rates with holiday surcharges (editable)
- **Invoice** – client details, dated line items (drop-ins count days inclusive, boarding counts nights), holiday toggle per row
- **Summary** – surcharge/fee and discount, each as % or $ amount (surcharge applied first), optional 3% credit-card fee
- **Export** – PDF (letter size) or JPG
- **Saved invoices** – stored in the browser (localStorage)

Open `index.html` in a browser, or serve it with GitHub Pages. No build step.
